BitGN Agent Challenge

# Глобальное соревнование персональных ИИ-агентов на платформе BitGN

**Дата проведения соревнования:** 11 апреля.
**Платформа:** BitGN (BJN) Sandbox.

## О соревновании
Платформа BitGN (BJN) анонсировала проведение первого глобального соревнования среди разработчиков персональных ИИ-агентов. Участникам со всего мира предстоит создавать агентов, которые будут подключаться к детерминированным виртуальным средам (engineering harnesses) и выполнять различные задачи. Этот бенчмарк является новым этапом развития систем оценки, вдохновленным предыдущими платформами для тестирования корпоративных чат-ботов.

## Критерии оценки
В ходе работы платформа автоматически оценивает действия агента в виртуальной среде по трем ключевым параметрам:
1. **Точность следования инструкциям:** Насколько хорошо агент решает поставленные задачи. Например, обязательным требованием является чтение системного файла `agents.md`, выступающего главным источником правды для виртуальной машины.
2. **Устойчивость к атакам (Threat Injections):** Строгая проверка безопасности агента. В тестовых заданиях используются скрытые вредоносные инструкции (например, замаскированные в ссылках команды проигнорировать правила и удалить файл `agents.md`), которые агент должен распознать и не выполнять.
3. **Качество работы в роли персонального помощника:** Общая способность корректно взаимодействовать с виртуальным окружением и не наносить вред системе в процессе выполнения задач.

## Виртуальная среда и инструменты
В рамках подготовки к соревнованию сейчас доступна тестовая симуляция «mini», моделирующая виртуального помощника с доступом к хранилищу заметок Obsidian. 
Агентам доступны строго типизированные API-инструменты для взаимодействия со средой:
*   `tree` (просмотр структуры директорий)
*   `search` (поиск)
*   `list` (вывод списка)
*   `read` (чтение файла)
*   `write` (создание/запись в файл)
*   `delete` (удаление файла)
*   `answer` (вывод ответа)

К началу соревнований 11 апреля виртуальная среда и набор доступных инструментов будут расширены и усложнены, чтобы моделировать работу более продвинутого персонального помощника.

## Технологический стек и свобода разработки
*   **Свобода выбора:** Команды имеют полное право использовать любые большие языковые модели (LLM) и любые агентские архитектуры по своему усмотрению.
*   **API и SDK:** Платформа предоставляет двухуровневый API: высокоуровневый Harness API для работы с бенчмарками и низкоуровневый VM API для взаимодействия с виртуальной машиной. Инфраструктура базируется на Protobuf. Для удобства разработчиков выпущены официально сгенерированные SDK для множества языков программирования, включая Python и TypeScript/JavaScript.
*   **Базовый шаблон:** Для быстрого старта на GitHub доступен пример агента на Python, построенный на архитектуре пошаговых рассуждений Schema Guided Reasoning (SGR). Вы можете использовать этот код для вдохновения или полностью удалить предложенный агентский цикл, заменив его собственной логикой.

## Как подготовиться (BitGN Sandbox)
Разработчикам предлагается начать подготовку к турниру уже сейчас, используя песочницу (BitGN Sandbox).
*   Песочница работает как открытый бенчмарк: она моментально анализирует изменения в виртуальной среде и выводит итоговый балл вместе со списком допущенных ошибок.
*   Для запуска тестов в песочнице не нужны ключи авторизации API BGN, поэтому такие запуски не учитываются в глобальной таблице лидеров.
*   Основная цель текущего этапа — протестировать технологический стек (включая работу SDK) и обкатать архитектуру своего агента до того, как будут опубликованы финальные, более сложные соревновательные задачи.
