- `agent_loop.py:81` was NOT updated: `call_llm(strategy.system_prompt, retry_msgs, model, nextstep_type)`

- **Type**: TOOL_ERROR (infrastructure — function signature mismatch)

## Recommended Fix
Add `""` as the second argument (system_dynamic) in agent_loop.py:81:
```python
# Before:
job = call_llm(strategy.system_prompt, retry_msgs, model, nextstep_type)
# After:
job = call_llm(strategy.system_prompt, "", retry_msgs, model, nextstep_type)
```

This is a 1-character functional change. The Nebius backend concatenates system_static + system_dynamic anyway, so passing "" as dynamic preserves exact behavior. A future cycle can split the ExecutionStrategy prompt into static/dynamic for Anthropic caching benefit.
