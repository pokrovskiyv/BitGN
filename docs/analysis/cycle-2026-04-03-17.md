### Root Cause
**Classification**: EDGE_CASE — threshold mismatch between gate and fallback
**File**: `pac1-py/verify.py` line 228 (GREEN zone)
**Generalizability**: HIGH — affects ALL security tasks that reach budget exhaustion

Two security layers have mismatched thresholds:
1. `pre_completion_gate()` (line 157): fires at `cumulative_threats >= 3`
2. `_fallback_outcome()` (line 228): fires at `cumulative_threat_count >= 5`

When a security task accumulates 3-4 threats:
- During execution: the gate warns the model ("HOLD: Multiple security threats detected")
- Model ignores the warning (or is challenged but doesn't change outcome)
- Model exhausts budget without reporting DENIED_SECURITY
- Fallback fires → threshold is 5 → returns CLARIFICATION or OK instead of DENIED_SECURITY
- The gate's effort is wasted because the fallback has a looser threshold

This was identified as a secondary finding in cycle-2026-04-03-16 analyst report.

### Why this is NOT a prompt fix
- Cycle 2026-04-02-20: outcomes.md DENIED_SECURITY boundary expansion → REGRESSED
- Cycle 2026-04-02-23: inbox DENIED_SECURITY evidence challenge → REGRESSED
- Prompt changes don't work reliably on free-tier models (session 2026-04-01: code 100%, prompts ~0%)
- This fix aligns an existing code threshold — pure consistency fix

### Recommended Fix
Change `_fallback_outcome()` security threshold from 5 to 3:
- Line 228: `if cumulative_threat_count >= 5:` → `if cumulative_threat_count >= 3:`
- 1 line changed, GREEN zone, no prompt changes

### Safety
- `pre_completion_gate` already fires at 3 and was accepted (cycle 15, IMPROVED_WITH_REGRESSION)
- The gate gives the model 2 chances to reconsider at threshold 3 — so by the time fallback fires, the model already had opportunities to self-correct
- For non-security tasks with false-positive threats: if cumulative_threats reaches 3 AND model budget-exhausts, DENIED_SECURITY is the safest fallback (costs at most 1.0 points; injection compliance can cost more)
- "Bias toward security rejection" is a stated design principle in CLAUDE.md
