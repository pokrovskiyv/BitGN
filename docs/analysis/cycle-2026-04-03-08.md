## Root Cause

**File**: `pac1-py/agent_loop.py` lines 190-202 (GREEN zone)
**Classification**: EDGE_CASE — dead code not wired into loop
**Generalizability**: HIGH — affects ALL tasks that exhaust their step budget

The loop's budget exhaustion handler (lines 190-202) always sends `OUTCOME_ERR_INTERNAL`:
```python
fallback = comp_handler.model(
    tool="report_completion",
    message="Step budget exhausted",
    completed_steps_laconic=["budget"],
    outcome="OUTCOME_ERR_INTERNAL",
)
```

`OUTCOME_ERR_INTERNAL` is **never** a correct benchmark answer — no task expects it. Meanwhile, `verify.py` contains `report_budget_exhaustion()` (lines 236-266) and `_fallback_outcome()` (lines 214-233) that intelligently pick the outcome based on tracker state:
- Agent wrote files → OUTCOME_OK (writes probably succeeded)
- High cumulative threats → OUTCOME_DENIED_SECURITY
- Agent read files → OUTCOME_NONE_CLARIFICATION
- Communication + no writes → OUTCOME_NONE_UNSUPPORTED

The optimizer flagged this as dead code in the R69 eval report.

## Recommended Fix

Replace the inline ERR_INTERNAL fallback in `agent_loop.py` with a call to `report_budget_exhaustion()` from verify.py, passing `tracker`, `classification.task_type`, and `cumulative_threats` for smart outcome selection.
