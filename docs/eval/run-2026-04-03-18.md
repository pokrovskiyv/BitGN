### Red Team Finding (for future cycles)
The `_MIN_STEPS` gate shares `completion_gate_count` (cap=2) with security gates. If min-steps fires first, it burns a slot that security gates need. Fix: give min-steps its own counter, or don't increment `completion_gate_count` for it.
